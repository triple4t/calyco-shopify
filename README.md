# Calyco Shopify Theme (Lightweight)

A modern Shopify theme built with React components using the React Islands pattern. This is the lightweight version designed to meet Shopify's 50MB theme size limit.

## 🎯 **Theme Features**

- **React Components**: Hero, Pillars, ColorStrip, Features, Testimonials, CTA
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Shopify Integration**: Full e-commerce functionality
- **Customizable**: Easy content management through Shopify admin

## 📁 **What's Included**

- ✅ **Core Theme Files**: Layout, templates, sections, snippets, config
- ✅ **React Bundle**: Built JavaScript and CSS (calyco.js, calyco.css)
- ✅ **Essential Assets**: Logo and core theme assets
- ✅ **Lightweight**: Under 50MB for easy Shopify import

## 🚀 **Getting Started**

### **Import to Shopify**
1. Go to Shopify Admin → Online Store → Themes
2. Click "Add theme" → "Connect from GitHub"
3. Select this repository and choose the `lightweight-theme` branch
4. Import and customize

### **Customize Content**
- Edit headlines, images, and CTAs through Shopify theme customizer
- All React components are fully configurable
- Real-time preview of changes

## 📝 **Note About Images**

This lightweight version includes:
- ✅ **Core Theme Assets**: Logo, React bundle, essential files
- ❌ **Heavy Image Assets**: Product images, inspiration photos, hero backgrounds

**To add images:**
1. Upload images through Shopify Admin → Content → Files
2. Reference them in your theme customizer
3. Or add them to your product collections

## 🔧 **Development**

For developers who want to work with the full source:
- Clone the main repository: `https://github.com/triple4t/calyco-shopify.git`
- Run `npm install` and `npm run build`
- Push updates to GitHub for auto-sync
